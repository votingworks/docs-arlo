# Standardized Contests File

A standardized contests file tells Arlo which contests to expect and what their correct names are.

1. **Open a spreadsheet program** and create a new spreadsheet.
2. **Add two columns:**
   * **Contest Name (Column A):** the name of each contest, entered exactly as it appears in your election management system (EMS).
   * **Jurisdictions (Column B):** each participating jurisdiction that has the contest on its ballots. If all participants have the contest, enter “all.”
3. **Enter the data,** with one row for each contest.
4. **Save the file as a .csv.**

![](<../../.gitbook/assets/image (73) (1).png>)

{% hint style="warning" %}
A third column titled "Choice Names" can be added to help standardize candidate names as well. Candidate names should be listed all in one cell like "Conine, Zach;Elliott, Bryan;Fiore, Michele;Hendrickson, Margaret;None of These Candidates" Use semi-colons to separate each name.
{% endhint %}

When the file is ready, upload it in the Participants & Contests section of Arlo:

1. **Select Browse** and choose the standardized contests .csv file you created.
2. **Select Upload File.**
3. **Select Next.**
