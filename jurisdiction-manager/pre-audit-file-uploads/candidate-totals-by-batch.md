# Candidate Totals by Batch

In order to conduct a batch comparison risk-limiting audit, Arlo needs candidate vote totals for each batch.

1. **Open a spreadsheet program** and create a new spreadsheet.
2. **Add your columns:**
   * **Batch Name (Column A):** the name of each batch. These must match the batch names in your ballot manifest.
   * **Candidate or selection names (additional columns):** one column for each candidate or selection in the target contest. Your audit administrator will provide these names because they **must match** how candidate names were entered into the Arlo Audit Setup.
3. **Enter the data** for your county or jurisdiction, with one row for each batch.
4. **Check your numbers.**
   * Make sure the number of batches matches the number of batches in your ballot manifest.
   * Make sure the candidate totals are correct.
5. **Save the file as a .csv.**
